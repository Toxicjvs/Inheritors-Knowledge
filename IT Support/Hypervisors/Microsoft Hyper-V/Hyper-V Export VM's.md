Open Hyper-V Manager, Find the VM you would like to export. 

1. Right click on the VM from the list and click Export

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Images/Hyper-V%20Export%20VM's/image-1.png)

2. Export Virtual Machine will popup, Browse to the place you would like the VM to saved to.

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Images/Hyper-V%20Export%20VM's/image-2.png)

3. Under Staus it will show the Exporting % 

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Images/Hyper-V%20Export%20VM's/image-3.png)

4. Open the folder you saved it to and make sure that all the Virtual hard disks are there along with the VM configuration files. 

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Images/Hyper-V%20Export%20VM's/image-4.png)
