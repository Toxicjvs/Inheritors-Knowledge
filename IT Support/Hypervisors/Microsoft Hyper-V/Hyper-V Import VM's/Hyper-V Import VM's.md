1. Open Hyper-V Manager, Within the Action section on the right side slect "Import Virtual Machine".

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-1.png)

2. Click "Next".

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-2.png)

3. Browse and locate the VM foler you would like to import then click "Next".

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-3.png)

4. This when should allow you to select the VM to import. Then click "Next"

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-4.png)

5. Select "Copy the virtul machine (create a new unique ID)" then click "Next"

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-5.png)

6. This should then be able to choose the destination. It will show Hyper-V folders by default. Feel fre to change the folders. If you do change the location please select "Store the virtual machine in a different location". When finished click "Next" 

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-6.png)

7. Same as before select the location for the virtual hard disks. When done click "Next"

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-7.png)

8. Click "Finish

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-8.png)

9. The files wil be copied over to the target location, When finished the VM will show in the Hypver-V Host in a saved state.

![alt text](https://github.com/Lord-Sheldon/Inheritors-Knowledge/blob/Work-in-Progress/IT%20Support/Hypervisors/Microsoft%20Hyper-V/Hyper-V%20Import%20VM's/image-9.png)
