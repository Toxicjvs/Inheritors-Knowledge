1. Open TreeSize and Select a Drive or Folder to Scan
Start the Program: After launching TreeSize, you’ll see the main interface.
Select a Drive or Folder: Click on the “Scan” button or select the “Select Directory” option from the File menu.
To scan a whole drive (like C: or D:), choose the drive letter.
To scan a specific folder, browse for the folder on your system.

2. Start the Scan
After selecting a drive or folder, click the "Start Scan" button.
The program will analyze the selected location. The scan may take some time depending on the size of the drive or folder.

3. View the Scan Results
Once the scan is complete, TreeSize will present a detailed overview of how space is used on your selected drive or folder.
Tree View: On the left-hand side, you’ll see a hierarchical folder structure.
Detailed Information: On the right side, you’ll see details such as the size, number of files, and number of folders for each item.

4. Explore the Data
Use the Tree View: Expand folders in the left-hand tree view to see which folders or files take up the most space.
Sort by Size: You can sort by the "Size" column to quickly identify large files and folders.
File Types: In the "File Types" tab, you can see which types of files (e.g., images, videos, documents) are using up the most space.

5. Analyze Space Usage
Pie Chart View: In addition to the tree view, TreeSize provides a pie chart that visually represents disk usage by folder or file type.
File System Usage: You can also see how your disk space is used by file systems, like NTFS or FAT32, which can help in managing storage.

6. Clean Up Disk Space
Delete Files: If you find large or unnecessary files/folders, right-click on them in the tree view, and select the option to delete them.
Export Reports: You can export the scan results as a report by selecting the "Export" button, which allows you to save the results in CSV, Excel, or text format.

7. Use the Search Function
TreeSize offers a search tool that lets you find specific files across your system.
In the "Search" tab, enter search terms (e.g., file name or extension) to locate files on your system. The results will show all instances of that file type.

8. Customize TreeSize Settings
Set Filters: You can filter out certain file types or sizes from the scan. For example, you can ignore files below a certain size threshold.
Change Display Settings: Go to “Options” > “Settings” to change the way data is displayed or adjust how the scan is performed.

9. Use the Scheduler (Pro Version Only)
If you're using the Pro version of TreeSize, you can schedule scans to run automatically.
Go to “Options” > “Scheduled Scan” and set up how often and when the program should run.

10. Close the Program
Once you're done analyzing and cleaning up your disk space, simply click "File" > "Exit" to close TreeSize.
Tips and Best Practices
Regular Scanning: Run TreeSize regularly to monitor disk space usage and avoid running out of space.
Backup Before Deleting: Always make sure to back up important data before deleting files.
Use "Size" Column for Quick Cleanup: Sorting by size in the "Size" column helps you quickly identify large files that may be unnecessary.
